The current version includes a Java application entry point, Maven configuration, Spring Web MVC dependencies, and a basic application-context test. **Technologies:** Java, Spring Boot, Spring Web MVC, Maven, JUnit.

A simulation-based prototype with a Python sensor simulator, Spring Boot API, React dashboard, anomaly detection, and a Tamil/English voice assistant. ESP32 firmware, physical sensor integration, and relay control are planned and not included.

**Technologies:** Java, Spring Boot, MySQL, React, Python, Flask, scikit-learn, Docker Compose, Ollama.

[Read the public project overview](https://github.com/dhineshv-dev/dhineshv-dev/blob/main/projects/smart-motor.md). The source repository is private.

## Run Locally

**Requirements:** Node.js 20 or newer is recommended.

```bash
git clone https://github.com/dhineshv-dev/placement-portfolio.git
cd placement-portfolio
npm install
npm run dev
```

Open the local URL shown in the terminal (typically `http://localhost:5173`).

## Production Build

```bash
npm run build
npm run preview
```

## Customize

- Edit `src/data.js` to update skills, projects, and links.
- Edit `src/components/` to change the page sections.
- Update `tailwind.config.js` and `src/index.css` for theme styling.
- Replace `public/resume.pdf` with your current resume. **Note:** this file is publicly downloadable when deployed.
